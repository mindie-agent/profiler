# mindie-profiler 0.5.11

[English](profiler-0.5.11.en.md)

本维护版本修复了正式发布流程与客户端自动更新链路中的依赖顺序校验，配套已正式发布并通过存量客户端升级验收的 [`mindie-sim 0.9.10`](https://github.com/mindie-agent/sim)。核心剖析与核算引擎保持与 `0.5.10` 一致；既往历史采集与精度实验数据原样保留，不重标为本版本的新增实测。

- **一等依赖完整性门禁**：上游第一方依赖必须通过已发布客户端的完整 Release 校验（含构件、校验和与元数据），不再仅凭 Git 正式标签存在就视为可交付。
- **先验收后公开的不可变发布链路**：正式发布从受保护主分支启动，必须在完整安装包构建、基准测试、校验和核对及真实客户端升级验收全部通过后，才公开不可变 Release。
- **存量更新器双阶段实测验收**：未经修改的已发布更新器先在隔离环境中自动发现新版本、构建完整运行时并验证 CLI 可用性；Release 公开后再从默认公网源完成二次真实升级验证。
- **历史 A3 回放物理契约解耦**：历史 A3 回放的适用性校验仅比对物理硬件参数、设备速率、算子调用边界与并行拓扑，说明性假设或来源描述文案的措辞调整不再误阻断相同物理输入的回放。
- **历史 A2 回放速率显式化与跨平台路径去重**：A2 回放测试显式声明保留配置中记录的 Vector 速率，避免默认硬件规格演进篡改历史测试输入；跨平台采集枚举统一按带目录边界的根目录相对路径去重，避免把具有相同前缀的不同目录误判为同一份采集。
- **Linux 预测子进程峰值内存精准计量**：Linux 预测工作进程改为读取当前可执行映像自身的 `VmHWM` 记录内存峰值，排除启动器在 `exec` 之前的历史驻留峰值；`512 MiB` 工作集上限保持强制生效，并新增真实父子进程回归测试验证内存释放后峰值记录仍完整保留。
- **默认追新与单调升级策略保持不变**：客户端默认拉取最新兼容版本与版本号单调递增约束保持不变；完整测试报告、基准结果与存量更新器升级取证随本次 Release 一并归档交付。
