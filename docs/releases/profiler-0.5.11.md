# mindie-profiler 0.5.11

[English](profiler-0.5.11.en.md)

本维护版修复正式发布与自动更新的依赖顺序和交付链路，配套已正式发布并通过旧更新器验证的 sim 0.9.10。分析引擎继承 0.5.10；历史采集与精度实验不重标为本版本的新测量。

- 依赖必须通过已发布客户端的完整 Release 校验，不能仅凭正式标签存在就被认定为可用。
- 发布从受保护主分支启动，完整安装包、基准、校验和及真实升级验收通过后才公开不可变 Release。
- 旧更新器在隔离环境中实际发现最新版、构建整代运行时并验证 CLI；公开后再从正常源执行升级。
- 历史 A3 回放的物理契约只比较硬件参数，说明性假设与来源文案的变化不再阻断相同物理输入；设备速率、调用边界和拓扑约束仍完整校验。
- A2 回放测试显式使用保留配置中记录的 Vector 速率，避免默认硬件规格演进篡改历史输入。跨平台采集枚举统一按根目录相对路径去重，不把不同目录的文本前缀当成同一采集。
- Linux 预测子进程使用当前可执行进程的 `VmHWM` 记录内存峰值，避免把启动者在 exec 前的历史峰值计入预测；512 MiB 限制保留，并通过真实父子进程验证释放内存后峰值仍保留。
- 默认追最新版与单调升级保持不变。实际测试结果、基准和旧更新器升级证据随发布交付。
