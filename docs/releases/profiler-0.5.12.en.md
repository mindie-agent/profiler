# mindie-profiler 0.5.12

[中文](profiler-0.5.12.md)

This release pairs with formally published [`mindie-sim 0.9.11`](https://github.com/mindie-agent/sim/releases/tag/v0.9.11), adding C7 collective-readiness extraction, HCCL and native-call (`BIND1`) relational attribution, active-pipe PMU measured supply (`mindie-profiler-measured-supply/1`), and bounded active-event memory pools during Decode forward segmentation. Historical captures and fleet accuracy benchmarks are not relabeled as new measurements.

- **CANN 9.x Steady-State Native MSPTI / `aclprof` Collector (`mindie-profiler-capture/1`)**: Adds the `mindie-profiler capture` CLI subcommand, `capture_profile` / `prepare_standby_session` / `mark_capture_step` standby session controls, and native `mindstudio_profiler_output` (`op_summary_*.csv` / `task_time_*.csv`) discovery and parsing.
- **Collective Readiness Extraction (`mindie-profiler/collective-readiness/1`)**: Adds `read_collective_readiness` and the C7 `collective_readiness` section, joining `COMMUNICATION_OP`, `COMMUNICATION_TASK_INFO`, and `COMMUNICATION_SCHEDULE_TASK_INFO` via real `TASK.taskType` / `globalTaskId` / `opId` / `connectionId` relational keys under guarded read-only SQLite deadlines, emitting per-`(rank_id, communicator, collective)` call ordinals, and keeping unjoined causal predecessors explicitly `unknown`.
- **Native-Call (`BIND1`) Correspondence & HCCL Alias Union Deduplication**: `StructureTargets` and `StructureMapper` index `mindie-sim/native-call-binding/1` signatures and rank-local HCCL raw aliases while verifying both current and historical `graph_id` seals. Full-window tracking (independent of `mapping_limit`) deduplicates `COMPUTE_TASK_INFO` and `COMMUNICATION_OP` presentations of one HCCL call via exact interval union, while CSV-only or `connectionId`-less schemas remain explicitly `unresolved`.
- **Active-Pipe PMU Measured Supply & Sparse Attention MTE1 Service**: Adds `--aic-count`, `--deployment-image-id`, and `--sparse-geometry` to derive pure measured dual-load matrix pipe supply (`mindie-profiler-dual-load/1`) and certified R64 `KvQuantSparseFlashAttention` critical-owner MTE1 service rates (`mindie-profiler-resource-service/1`) strictly from active pipe counters rather than elapsed kernel duration, emitting explicit `limitations` whenever hardware capacity, R64 provenance, image digest consistency, or `status.json` preparation is absent or ambiguous.
- **Bounded Memory & Root-Bounded Rank Discovery**: `auto_segment_decode_forwards` projects in-flight events onto compact active records and tears down per-rank string/shape pools on window closure to enforce $O(\text{Active State})$ memory; rank directory inference stops strictly above `--root` so parent temporary directory names never pollute `rank_id`.
