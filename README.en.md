# `profiler` (`mindie_profiler` / `mindie-profiler`)

Standalone Ascend NPU performance profiler and cross-run comparison repository for MindIE Agent (`https://github.com/mindie-agent/profiler`), providing the `mindie-profiler` (`python3 -m mindie_profiler`) CLI for in-place read-only Ascend profiler accounting (`mindie-profile-summary/1` C7 JSON) and cross-run comparison receipts.

```bash
uv pip install git+https://github.com/mindie-agent/profiler@main
```
